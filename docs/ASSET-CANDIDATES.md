# Splatoon 3 UI 资源候选

以下文件只按文件名推测用途，当前没有复制或解压游戏资源。`.zs` 文件需要使用现有解包工具进一步查看。

## 优先查看

- `Layout/Cmn_SystemWindowPlace_00.Nin_NX_NVN.blarc.zs` / `Cmn_SystemWindowPlace_01...`：系统弹窗容器，最可能对应截图中的大张深色纸片。
- `Layout/Plz_WindowDrawn_00.Nin_NX_NVN.blarc.zs` / `Plz_WindowDrawn_01...`：Plaza 风格的手绘窗口。
- `Layout/Cmn_BgBlur_00.Nin_NX_NVN.blarc.zs`：窗口后方的模糊背景。
- `Layout/Cmn_FadeWipe_00.Nin_NX_NVN.blarc.zs`：页面切换或卡片出现时的过渡效果。
- `Layout/BtnMenuL_00.Nin_NX_NVN.blarc.zs`、`Layout/BtnTextLong_00.Nin_NX_NVN.blarc.zs`：大尺寸文字按钮。
- `Layout/SequenceBtn_00.Nin_NX_NVN.blarc.zs` / `SequenceBtn_01...`：流程确认按钮候选。

## 颜色、墨迹和装饰

- `UI/Icon/Zakka/Mpt_Painted_*.bntx.zs`：不同颜色的涂料材质候选。
- `UI/Icon/Zakka/Fig_PaintBrush*.bntx.zs`：刷子或涂鸦装饰候选。
- `UI/Icon/Zakka/Fig_StrapInkFish.bntx.zs`：墨鱼装饰候选。
- `UI/Icon/MngStage/Painted.bntx.zs`：涂色/墨迹图案候选。
- `Layout/Tml_Noise_00.Nin_NX_NVN.blarc.zs`：噪点或纸张颗粒效果候选。

## 按钮和小图标

- `UI/Icon/Manual/Btn/ManualBtnL_11_CNzh.bntx.zs`：中文大按钮贴图候选。
- `UI/Icon/Manual/Btn/ManualBtnS_Big_*.bntx.zs`：大号小按钮候选。
- `UI/Icon/Manual/Btn/ManualBtnS_Small_*.bntx.zs`：小号按钮候选。
- `Layout/BtnCheck_00.Nin_NX_NVN.blarc.zs`：确认/勾选按钮候选。
- `Layout/BtnSelectNum_00.Nin_NX_NVN.blarc.zs` / `BtnSelectNum_01...`：步骤数字或选择数字候选。
- `Layout/LoadingIcon_00.Nin_NX_NVN.blarc.zs`：加载动画候选。

## 字体

- 游戏原始中文字体包：`Font/Font_CNzh.Nin_NX_NVN.bfarc.zs`
- 当前网页使用的字体：`assets/fonts/DFP_GBZY7.ttf`
